# AETHER // OLED System Monitor & Zen Lab (Android Native App & Widget)

Мобильное приложение и нативный системный виджет в ультраминималистичном стиле **Nothing OS / OLED Noir** (чистый глубокий монохром `#000000` и `#FFFFFF`).

---

## 🖤 Ключевые возможности

### 1. Настоящий нативный виджет рабочего стола Android (4x2 / 2x2)
- **БЕЗ всплывающего видео / картинки в картинке**: плавающий PiP полностью исключен!
- **Настоящий AppWidget**: виджет размещается прямо в сетке домашнего экрана (launcher) Android.
- **Телеметрия в реальном времени**:
  - Точные цифровые часы моноширинным шрифтом.
  - Уровень заряда батареи (`%` и статус зарядки).
  - Использование оперативной памяти (RAM) в GB и процентах.
  - Статус сети (WIFI-6 / 5G-NR / ONLINE).
- **Кнопка быстрого запуска активной Zen-игры**:
  - На виджете отображается выбранная игра: `▶ ZEN #14: SOLAR SYSTEM [ИГРАТЬ]`.
  - Нажатие на виджет мгновенно открывает игру во весь экран за 0.1 секунды.
  - Кнопка `[ ◰ В ВИДЖЕТ ]` внутри приложения автоматически обновляет виджет и вызывает системный диалог закрепления на домашний экран (`AppWidgetManager.requestPinAppWidget`).

## 🚀 Как загрузить изменения в GitHub и собрать новый APK

1. Откройте ваш репозиторий: **`https://github.com/sobrjonvv-design/aether-monitor`**
2. Нажмите **Add file** ➔ **Upload files**.
3. Перетащите из этой папки (`AETHER_GITHUB_UPLOAD`):
   - `index.html`
   - `MainActivity.kt`
   - `AetherWidgetProvider.kt`
   - `widget_telemetry.xml`
4. Для обновления скрипта сборки:
   - В репозитории откройте папку `.github/workflows/main.yml`, нажмите иконку карандаша ✏️ (Edit) и вставьте содержимое файла `.github/workflows/main.yml` из этой папки.
5. Внизу нажмите зеленую кнопку **Commit changes**.
6. Перейдите во вкладку **Actions** вверху:
   - Дождитесь завершения сборки **Build AETHER Android APK with Native Widget** (зеленая галочка).
   - Внизу страницы сборки скачайте готовый APK: **`AETHER-OLED-Widget-APK`**!
