# AETHER // OLED NET & SYSTEM MONITOR (Android PWA)

Полноценное ультраминималистичное мобильное веб-приложение в строгом стиле **OLED Black & White** (в духе Nothing OS, Dieter Rams и кибернетических телеметрических приборов).

---

## 🖤 Концепция и Дизайн-система

- **OLED Black Palette**: 
  - Фон: Чистый `#000000` (100% экономия заряда на OLED/AMOLED матрицах).
  - Элементы и текст: Чистый белый `#FFFFFF` и нейтральные серые тона (`#888888`, `#4C4C4C`, `#1C1C1C`).
  - **Абсолютно никаких цветных акцентов** — строгая эстетика монохрома.
- **Типографика**:
  - `JetBrains Mono` для всех числовых метрик, IP-адресов, частот процессора и таймстампов.
  - `Inter` для лаконичных заголовков и системных подписей.
- **Концентрические кольца & HiDPI Графика**:
  - Векторные SVG-кольца с анимированным вращением пунктиров и шкал.
  - HTML5 Canvas с поддержкой `window.devicePixelRatio` (60 FPS, отсутствие размытия на экранах высокой плотности).
- **Тактильный отклик**:
  - Тактильная вибрация через `navigator.vibrate` (Haptic feedback).
  - Синтезированные микро-клики через Web Audio API (без внешних аудиофайлов).

## ⚡ Функциональные модули

### 1. Интерактивный тест скорости (SPEED)
- Замер **Download**, **Upload**, **Ping (RTT)** и **Jitter**.
- Вращающиеся концентрические кольца прогресса с динамическим `stroke-dashoffset`.
- Живой график стабильности потока на Canvas с отрисовкой пиковых значений в реальном времени.
- Переключатель единиц измерения: **Mbps ⟷ MB/s**.
- Выбор целевого узла (Cloudflare Edge, AWS Frankfurt, Equinix Amsterdam, Hetzner, Synthetic).

### 2. Системные ресурсы и железо (SYSTEM)
- **Живой мониторинг батареи**: процент заряда, статус (Charging / Battery), температура с точностью до десятых долей градуса, напряжение и примерное время работы (интеграция с `navigator.getBattery()`).
- **Оперативная память (RAM)**: заполнение, визуальное круговое кольцо, интеграция с `performance.memory` и кнопка принудительной очистки кэша (`Purge System Cache`).
- **Внутреннее хранилище (ROM)**: 24-сегментная шкала (Nothing style), распределение между System Firmware, Apps, Media и Web Cache (интеграция с `navigator.storage.estimate()`).
- **8-ядерный процессор (CPU Scheduler)**: архитектура Big.LITTLE (Cortex-X3, Cortex-A715, Cortex-A510), живая пульсация частот и интерактивный просмотр профиля ядер по тапу.
- Детектор частоты обновления дисплея (60Hz / 90Hz / 120Hz OLED).

### 3. Трекер интернет-трафика (TRAFFIC)
- Круговой концентрический индикатор месячной квоты с процентом и остатком.
- Учет трафика за день и месяц с разделением: Мобильная сеть (5G/LTE), Wi-Fi 6 и фоновая телеметрия.
- 24-часовая гистограмма почасовой плотности трафика со штрихованными столбцами.
- Модальное окно для установки лимита трафика и кнопка сброса счетчиков.
- Живой индикатор скорости обмена данными в реальном времени (`↓ TX / ↑ RX`).

### 4. Экран логов и сетевой статистики (LOGS)
- Терминальный стрим системных и сетевых событий с таймстампами `HH:mm:ss.ms`.
- Фильтрация логов: `ALL`, `NET`, `SYS`, `SPEED`, `WARN`.
- Кнопка **Ping Burst** (серия диагностических эхо-запросов к шлюзу).
- Управление: Пауза стрима, очистка буфера, экспорт логов в текстовый файл (`.txt`).
- Диагностические параметры интерфейса: Local IP, Gateway, DNS, Effective Connection Type, Packet Loss.

## 🚀 Запуск и установка как PWA на Android

Приложение полностью автономно и собрано в едином файле [`index.html`](file:///C:/Users/user/.gemini/antigravity/scratch/oled-system-monitor/index.html).

### Способ 1: Открытие в браузере
Просто откройте файл `index.html` в Google Chrome или любом мобильном браузере на Android.

### Способ 2: Локальный веб-сервер
Для тестирования PWA-установки на смартфоне запустите локальный сервер:
```bash
# Через Python:
python -m http.server 8080 --directory "C:\Users\user\.gemini\antigravity\scratch\oled-system-monitor"

# Или через Node.js:
npx serve "C:\Users\user\.gemini\antigravity\scratch\oled-system-monitor" -p 8080
```
Затем перейдите по адресу `http://<IP-вашего-компьютера>:8080` на телефоне и нажмите в меню Chrome: **«Добавить на главный экран»** (Add to Home screen / Install app).
