# AETHER // OLED System Monitor & Zen Lab (Android App & Widget)

Мобильное приложение и системный виджет в ультраминималистичном стиле **Nothing OS / OLED Noir** (чистый монохром `#000000` и `#FFFFFF`).

---

## 🖤 Особенности проекта

- **16 уникальных антистресс-игр (Zen Lab)**:
  1. `Zen Kinetic Sand` — кинетический песок с вихревым и репульсивным гравитационным полем.
  2. `Bonsai Fractal Trimmer` — рекурсивный фрактальный бонсай со звуком роста ветвей.
  3. `Liquid Mercury Pool` — черная жидкая ртуть с физикой круговых волн и интерференцией.
  4. `Mechanical Tally Clicker` — стальной механический кликер с тактильной отдачей и звуком шестерни.
  5. `Orbital Gravity Slingshot` — запуск спутников на кеплеровские орбиты вокруг черной дыры.
  6. `Magnetic Iron Filings` — 195 ферромагнитных игл, выстраивающихся вдоль векторного магнитного поля.
  7. `Kaleido-Matrix Painter` — 8-осевое зеркальное рисование чистым монохромным светом.
  8. `Dot Constellations Harp` — звездная арфа с соединением созвездий пентатоническими аккордами.
  9. `Brass Morse Telegraph` — латунный телеграфный ключ с точками, тире и звуком зуммера 750 Гц.
  10. `Quantum Photon Cloud` — квантовая сеть из 40 фотонов с ударной волной.
  11. `Bioluminescent Mycelium` — живые ветвящиеся светящиеся корни-молнии от кончиков пальцев.
  12. `Cyber-Synapse Neural Web` — нейросеть с импульсами тока по аксонам.
  13. `Event Horizon Vortex` — 350 звезд в аккреционном вихре черной дыры с квазарным выбросом.
  14. `Solar System Gravity` — Солнечная система: Солнце, планеты, пояс из 80 астероидов и кометы.
  15. `Spacetime Gravity Fabric` — эластичная сетка пространства-времени, деформирующаяся под пальцем.
  16. `Nixie Tube Tesla Counter` — газоразрядные индикаторы ИН-14 с электрической дугой.

- **Нативный виджет для домашнего экрана Android**:
  - Быстрое закрепление любой активной игры на рабочий стол кнопкой `[ ◰ В ВИДЖЕТ ]`.
  - Запуск игры в отдельном легковесном окне или PiP.

- **Мониторинг железа**:
  - Speed Test с концентрическими кольцами.
  - Монитор батареи, RAM, ROM и 8-ядерного процессора Big.LITTLE.
  - Учет интернет-трафика и живой терминал логов.

## 📦 Автоматическая сборка APK через GitHub Actions

В репозитории настроен рабочий процесс `.github/workflows/main.yml`, который при каждом коммите автоматически компилирует APK с помощью Gradle:
- Готовый установочный файл: **`AETHER-OLED-Widget-APK`** (`app-debug.apk`) во вкладке **Actions** -> **Artifacts**.
